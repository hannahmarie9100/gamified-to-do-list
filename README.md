# gamified-to-do-list

A web-based task management application that uses gamification to motivate users

## Features

- Create, edit, and complete tasks
- Gamified reward system tied to task completion
- persistent task storage using the browser LocalStorage API
- Dynamic UI updates without page reloads

## Tech Stack

- JavaScript
- HTML
- CSS
- Browser LocalStorage API

## Getting started

1. Clone the repository
   ```bash
   git clone https://github.com/hannahmarie9100/gamified-to-do-list.git
   ```
2. Open index.html in your browser
